# Changelog policy

Record user-visible changes under Added, Changed, Deprecated, Removed, Fixed or Security. Every release PR updates `[Unreleased]`; the release owner moves those entries to a dated version. Link the PR and release note when creating a GitHub release.

Never include personal data, credentials, private client information or unapproved commercial claims. “Major overhaul” describes project scope and does not by itself determine semantic versioning.
